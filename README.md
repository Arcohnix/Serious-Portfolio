# Sanket Desai — Portfolio

A personal portfolio documenting my work as a software engineer: the systems I build, the engineering decisions behind them, and the ideas I am exploring.

The site brings together selected project case studies, engineering notes, my technical toolbox, and my education and experience. Project pages include implementation context, architecture, tradeoffs, and screenshots where available. The portfolio also links to my GitHub, Docker Hub, LinkedIn, and downloadable resume.

The work spans backend and distributed systems, AI applications, infrastructure, and Android development. The case studies describe individual projects and their implementation details; they are intended to make the work and its engineering choices easy to explore.

## Portfolio sections

- **Selected work:** project summaries and detailed case studies.
- **Engineering notes:** articles about system design, retrieval, and agent workflows.
- **Toolbox and practice:** technologies and engineering areas I work with.
- **Experience and education:** a timeline of my learning and project journey.
- **Contact:** professional links and ways to get in touch.

## Built with

Next.js, React, TypeScript, Tailwind CSS, MDX, Motion, and Shiki.
